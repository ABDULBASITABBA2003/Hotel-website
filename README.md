# Hotel-website

This project is a responsive hotel website designed for mobile users. It allows visitors to search for accommodations, view special offers, read customer reviews, and access travel-related blog posts. The website provides a seamless and engaging user experience.

## Project Overview
The Hotel-website is a modern, mobile-first landing page for an apartment booking service. It features a clean design with dynamic content rendering using vanilla JavaScript.

## Features
- **Mobile-Responsive Design**: Optimized for a great experience on smartphones and tablets.
- **Dynamic Content**: Offers, reviews, and blog posts are rendered dynamically via JavaScript.
- **Search Functionality**: A prominent search bar for finding accommodations.
- **Newsletter Subscription**: Integrated newsletter signup form in the footer.
- **Interactive Navigation**: Hamburger menu for mobile navigation.
- **Social Media Integration**: Links to major social platforms.

## System Architecture
The project follows a simple static web architecture:
- **HTML5**: Defines the structure of the page.
- **CSS3**: Handles the styling and responsive layout using Grid and Flexbox.
- **Vanilla JavaScript**: Manages dynamic content rendering and UI interactions (like the mobile menu).

Detailed architecture documentation can be found in the [docs/](./docs/) directory.

## Tech Stack
- **Languages**: HTML5, CSS3, JavaScript (ES6+).
- **Fonts**: Montserrat, Urbanist (via Google Fonts).
- **Icons**: Custom PNG assets located in the `assets/` folder.

## Setup and Installation
Since this is a static website, no complex installation or build process is required.

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-repo/hotel-website.git
    ```
2.  **Open the project**:
    Simply open the `index.html` file in any modern web browser.

Alternatively, you can use a local development server like "Live Server" in VS Code for a better experience.

## Usage
- **Navigation**: Use the header menu to navigate between different sections. On mobile, click the hamburger icon to open the menu.
- **Searching**: Use the search bar in the hero section to simulate searching for an apartment.
- **Viewing Offers**: Scroll down to see the latest "Special offers".
- **Reading Reviews**: Check the "Reviews" section for customer feedback.
- **Newsletter**: Enter your email in the footer to subscribe.
