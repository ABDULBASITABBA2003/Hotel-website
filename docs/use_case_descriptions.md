# Use Case Descriptions

Detailed descriptions for the core functions of the Hotel Website.

## 1. Search for Apartment
| Field | Description |
|---|---|
| **Actor** | Guest |
| **Description** | The guest uses the search bar to find available apartments for their vacation. |
| **Preconditions** | The guest has navigated to the website. |
| **Post-conditions** | The system displays relevant apartment options based on the search criteria (Note: Current implementation is a static search bar). |

## 2. View Special Offers
| Field | Description |
|---|---|
| **Actor** | Guest |
| **Description** | The guest browses the "Special offers" section to see discounted or featured accommodations. |
| **Preconditions** | The website has loaded the dynamic content via JavaScript. |
| **Post-conditions** | The guest sees a list of offers with images, titles, dates, and prices. |

## 3. Subscribe to Newsletter
| Field | Description |
|---|---|
| **Actor** | Guest |
| **Description** | The guest enters their email address in the footer section to receive updates and news. |
| **Preconditions** | The guest navigates to the footer of the website. |
| **Post-conditions** | The guest's email is submitted to the system (Note: Current implementation is a UI placeholder). |

## 4. Read Customer Reviews
| Field | Description |
|---|---|
| **Actor** | Guest |
| **Description** | The guest reads testimonials from other customers in the reviews section. |
| **Preconditions** | The website has loaded the review data. |
| **Post-conditions** | The guest gains insight into other users' experiences. |

## 5. Toggle Navigation Menu
| Field | Description |
|---|---|
| **Actor** | Guest |
| **Description** | The guest opens or closes the navigation menu on a mobile device. |
| **Preconditions** | The guest is using a mobile-sized screen. |
| **Post-conditions** | The navigation menu is displayed or hidden accordingly. |
